Frontend Testing
- For every page
  - Resize the window to be the full size of the screen, and about half the full screen size
    - For both of these, all text on the screen should be easily readable and images easily viewable without changing zoom
  - For user-input fields, ensure users aren't allowed to enter invalid characters. For example, a user should not be able to enter letters into a credit card field.
- For the inspect page
  - Given an option is selected, any other options which form a combination with it that doesn't exist in the inventory will be crossed out to indicate to the user that the combination isn't available.
